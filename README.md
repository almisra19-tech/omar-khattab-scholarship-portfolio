# Omar Khattab — Scholarship Portfolio

A responsive single-page portfolio website for an undergraduate scholarship application in Physical Culture (49.03.01).

## Preview / publish

This is a static website. To publish with GitHub Pages, open the repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will show the published URL in the Pages settings when deployment is ready.

## Edit your content

- `index.html` contains the page structure and the editable motivation letter/contact placeholders.
- `script.js` contains the club, training video, evidence gallery, project, extracurricular and document data. Add entries to its arrays to expand the portfolio.
- `styles.css` controls the visual design and responsive layout.

Add your own photos and documents to the repository (or link to a suitable hosted file) and update the corresponding entries. For video, set a card's `url` to a direct video file (`.mp4`, `.webm`, `.ogg`) or an embeddable player URL. A separate link is also provided for video URLs.

Replace every bracketed placeholder and verify all evidence and contact details before sharing the site with a scholarship committee. Do not publish sensitive personal documents unless you intend them to be public.
